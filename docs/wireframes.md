# UI Wireframes & Layouts

## Design Aesthetic
- **Theme:** Indian Flag Inspired "Fog" (Glassmorphism)
- **Primary Colors:** 
  - Saffron: `#FF9933` (Used for primary buttons, highlights, alerts)
  - White: `#FFFFFF` (Used for text, background accents)
  - Green: `#138808` (Used for success states, secondary buttons, icons)
- **Effects:** Frosted glass, soft gradients, blur effects, clean modern typography.

## Common Layout Structure
- **Top Navigation Bar:** Logo, Global Search, Notification Icon, User Profile Dropdown.
- **Sidebar:** Navigation links categorized by role.
- **Main Content Area:** Glassmorphism container with dynamic content.

## Dashboard Layouts

### 1. Citizen Dashboard
- **Welcome Banner:** Personalized greeting with a dynamic fog gradient.
- **Quick Stats:** 
  - Number of Eligible Schemes
  - Saved Policies
  - Active Notifications
- **Recent Activity:** Table or list of recently viewed policies.
- **Recommended Schemes:** Card grid showcasing schemes matching the user's profile.

### 2. Government Official Dashboard
- **Overview:** Policy Statistics (Total Published, Pending Approval).
- **Analytics:** Scheme Usage Analytics chart (Chart.js integration).
- **Recent Submissions:** List of policies awaiting approval.
- **Department Reports:** Quick links to generate activity reports.

### 3. Policy Search Page
- **Search Bar:** Prominent keyword search input.
- **Filters Panel (Sidebar):** Accordions for Category, State, Ministry, Status, and Date Range.
- **Results Area:** List or Grid view of policy cards with pagination.

### 4. Eligibility Checker Page
- **Wizard Interface:** Step-by-step form (Personal Details, Financial Info, Education, etc.).
- **Results View:** Summary dashboard of matched schemes with "Apply Now" buttons.
